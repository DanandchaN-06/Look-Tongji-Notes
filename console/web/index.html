LOOK TONGJI NOTES

从课堂录课，到复习知识库

采集课程素材，交给你选择的 Agent 写作，再校验并构建知识库。

第一次使用，从这里开始

填写账号并选一个保存资料的文件夹。

“知识库”是什么？

就是你电脑上的课程资料文件夹，按课程和课次保存字幕、课件、讲义、笔记及时间轴。写好笔记后，可以生成浏览器阅读网页，方便复习查找。

本地预览在你的电脑上阅读；发布到 GitHub Pages 会上传网页内容，公开范围由目标仓库和 Pages 设置决定。

首次配置向导

  1. 填写同济账号在「设置中心」保存，密码只写入本机 .env
  2. 选择知识库路径决定字幕、截图与网站的存放位置
  3. 配置视觉模型笔记需要读取课件截图，需一个能看图的模型
  4. 采集第一节素材下载课件；音频转写由哔哩哔哩云端 ASR 处理
  5. 生成笔记并构建知识库由 Agent 完成写作，控制台负责校验

发布到 GitHub Pages

        

        
发布会把生成的网页上传到目标 GitHub 仓库，并通过 Pages 提供访问地址。发布范围由仓库和 Pages 设置决定，先核对要公开的材料。

        
课程材料可能包含版权内容。发布前请确认你有权公开，并确保 .env、state/ 未被纳入站点。
