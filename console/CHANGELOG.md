# 控制台更新记录

## 0.3.0 — 2026-10-08

### Added
- Agent 工作台按课程与节次名称选择，展示教师、日期及任务范围，指令带完整课程信息；ID 作为高级定位。
- 通用 Agent 选择、交接指令保存、速查表格式选择及按任务校验产物。
- 首页操作流程、使用说明、全局反馈、键盘焦点和窄屏布局。
- 隔离的后端回归测试、真实 CLI 离线流程测试及浏览器测试。
- 项目虚拟环境与通用 Python 覆盖设置，Windows PowerShell 启动入口。

### Fixed
- 只下载课件后工作台无法识别节次；保留已有字幕路径，兼容旧课件索引。
- 手动换课残留其他课程节次，名称补全误丢生成结果，关闭浏览器时重复写入错误响应。
- 补充材料导入丢失节次 ID，设置页看不到操作结果。
- 刷新后丢失访问权限；连续 HTTP 请求复用旧请求体。
- 留空视觉密钥无法保存，同平台密钥误用到不同地址的风险。
- 空文件和教师讲义误判产物，显式课程 ID 被同节次 ID 覆盖。
- 时间轴校验指令缺少必需参数。
- 工作区任务并发写入、排队取消、启动期间取消及停止后残留预览进程。
- 日志异步响应混入其他任务、预览固定端口及未就绪就打开页面。

### Changed
- 所有产品说明和指令使用通用 Agent 名称；工具选择不绑定写作服务。
- 显示任务文件校验结果，不把退出码当成笔记已生成。
- 转写前明确说明云端音频处理。关闭浏览器与关闭后台服务的行为分别说明。
