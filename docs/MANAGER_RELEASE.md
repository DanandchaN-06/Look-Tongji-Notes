# 管理器 v0.5.0 · Windows x64 便携版

本版将控制台 V2 作为唯一入口的默认管理界面，同时保留原有课程阅读网页、CLI 和 Agent 工作流。发行物是便携 ZIP，不是 MSI 安装器。

## 下载与启动

从本 Release 下载 `Look-Tongji-Manager-0.5.0-Windows-x64.zip` 和 `SHA256SUMS.txt`。先校验 ZIP，完整解压到有写入权限的目录，再双击 `启动课程助手.cmd`：

- **1 管理控制台（V2）**：在“设置”填写自己的账号、资料目录和按需使用的模型接口；在“我的课程”同步和选择课程/课次，在“任务中心”查看进度、日志并恢复失败任务。
- **2 原有阅读网页**：浏览已经构建的课程资料。
- **3 安装 FFmpeg**：首次字幕转写需要；安装后重新打开管理器。
- **4 升级旧版并保留设置**：将新包解压到单独目录，再输入旧版的 `app` 目录路径。升级器只覆盖程序文件，并在旧版应用目录外生成校验备份；账号、设置、任务数据库、浏览器资料及课程目录保留在原位。

包内含 Python、课程登录所需的无界面浏览器、资料转换依赖及应用本地 VC++ 运行库，不需要手动安装 Python 或运行 pip。Agent 笔记由用户选择的 Agent 执行；视觉接口、LaTeX 编译和 GitHub Pages 发布按需配置。

## 本版功能

- V2 控制台统一设置、课程/课次浏览、任务列表、阶段进度、日志、取消和失败恢复。
- 重启后恢复持久化工作流；相同课次复用已缓存成果，避免重复下载。
- 支持素材成果校验、旧资料索引预览与安全迁移、阅读页面构建和打开。
- 通用 Agent 交接；控制台不会代替用户启动 Agent 或提交笔记。
- 原阅读网页、原 CLI 和原有 Agent 工作流保留。

## 验证与隐私

发行包由显式源码清单和经过 SHA-256 校验的 Python/浏览器运行时种子构建。包内不包含个人账号、登录会话、模型密钥、课程资料、任务数据库、缓存或浏览器配置文件。首次启动会创建空白配置；所有用户自行填写的设置保存在本地。

字幕识别会将音频发送到界面提示的外部识别服务。课程平台登录、ASR、视觉模型和 Agent 写作受账号、网络和第三方服务状态影响。Release 说明会列出本次实际完成的干净环境启动、页面、升级/回退和隐私验收结果；未实测的外部服务会明确标注。
