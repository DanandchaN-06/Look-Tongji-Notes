# 管理器 v0.4.4 · Windows x64 便携版

为原项目增加可选本地图形管理器，保留原有阅读网页、CLI 和 Agent 工作流。

## 下载与使用

下载 Assets 中的 `Look-Tongji-Manager-0.4.4-Windows-x64.zip`（约 293 MB），完整解压，双击 `启动课程助手.cmd`：

- **1 管理控制台**：首次设置账号与资料目录，选择课程/课次、提交采集任务、查看进度与日志、生成 Agent 交接指令。
- **2 原有阅读网页**：浏览已经生成的课程资料；空资料库也能打开。
- **3 安装 FFmpeg**：首次字幕转写需要，安装后重新打开管理器。

包内含 Python、课程登录所需的无界面浏览器、资料转换依赖及应用本地 VC++ 运行库，不需要手动安装 Python 或运行 pip。写笔记需要你自己选择的 Agent；视觉模型、LaTeX 编译和 GitHub Pages 发布按需配置。

详细步骤、功能范围、失败排查和资料目录说明：[管理器使用指南](https://github.com/DanandchaN-06/Look-Tongji-Notes/blob/main/docs/MANAGER_GUIDE.md)。

## 本版功能

- 课程与课次选择、字幕和组合素材采集、补充资料导入。
- 后台队列、真实数量与阶段进度、日志、取消、分课程批量恢复。
- 通用 Agent 及常见 Agent 的笔记/时间轴/A4 速查表交接，指定产物检查。
- 本机知识库同步、原网页构建与预览、发布准备与发布交接。
- 同课次缓存复用、完整性校验、并发互斥、分片续传和 FFmpeg 启动检测。

## 验证与隐私

已测试脱敏 ZIP 重新解压、空账号配置、中文及空格路径、首次并发启动、原网页构建、内置浏览器、材料转换与应用本地 VC++ DLL。当前电脑上管理器约 2 秒启动。

发行包不带个人账号、登录会话、模型密钥、课程媒体/字幕/笔记、固定本机路径或浏览器配置文件。下载者填写自己的配置。分享原始 ZIP，不要打包已经使用过的目录。

本版为 Windows 10/11 x64 测试版，未在全新实体电脑上验证完整课程流程。跨课次批量 ASR、真实视觉接口和 GitHub Pages 发布未全部端到端验证。下载速度取决于网络。

校验文件：`PORTABLE_SHA256.txt`。原作者署名、项目 MIT 许可及第三方许可说明保留。FFmpeg 单独安装，不包含在此 ZIP 中。
