# 管理器使用指南

管理器把课程配置、素材采集、后台任务、Agent 交接和阅读网页放到统一入口中。你选择课程和课次，管理器调用原项目 CLI 获取材料；笔记仍由你选择的 Agent 撰写。

## 下载与启动

普通 Windows 用户请到 [Releases](https://github.com/DanandchaN-06/Look-Tongji-Notes/releases) 下载 Windows x64 ZIP。GitHub 的“Code → Download ZIP”是源码，需要自行安装依赖。

1. 完整解压到有写入权限的文件夹，不能直接在压缩包里运行。
2. 双击 `启动课程助手.cmd`，选 **1 管理控制台**。
3. 首次字幕转写前，入口选 **3 安装 FFmpeg**，安装后重新打开管理器。
4. 原有阅读网页使用入口 **2**；首次打开没有课程时会显示空知识库，之后生成笔记并更新网页即可阅读。

便携版内置 Python、课程登录所需的无界面浏览器和资料转换依赖，打开管理器不需要运行 pip。视觉识别需要你自己的模型接口；Agent 写作需要你自己的 Agent；LaTeX PDF 编译、GitHub Pages 发布需要对应的额外工具。源码方式见 [console/README.md](../console/README.md)。

## 第一次使用的完整流程

### 1. 账号与保存设置

填写你自己的同济学号/工号和密码，保存凭据。选择课程资料的本机保存目录，填写网页显示名称和网页标题。视觉模型和 GitHub Pages 仓库按需配置，不需要在首次启动时全部填写。

查看环境检查。缺失的 FFmpeg 会影响音频抽取，未配置视觉模型会影响截图识图；请先补齐要使用的功能所需组件。账号和配置只保存在本机，发行包没有预填任何人的账号。

### 2. 选课与采集素材

在“选课与采集素材”查询最近课程或搜索课程/教师，确认学期、教师、课程和具体课次，再提交“仅转写字幕”或组合采集。可查询回放地址，导入自己的课件、讲义等补充材料。

字幕转写会沿用原项目的外部 ASR 服务，音频会上传用于识别，开始前阅读界面提示。下载成功得到的是输入材料，还没有自动完成学习笔记。

### 3. 任务进度

任务页面显示排队位置、当前阶段、耗时、实际下载量和日志，可以取消任务。下载有真实字节进度；云端识别不能确定剩余时间时显示阶段，不编造百分比。

同一课次默认复用有效 TXT/SRT 或已保存音频，ASR 重试也复用已有音频。确实需要重新识别时再选择强制重新转写。批量任务支持按课程的检查点和失败课次重试。

失败时先看“详细日志”的最后几行，区分下载、FFmpeg 抽取和 ASR 问题；不要连续重复提交相同任务。

### 4. Agent 写作工作台

明确选择课程和课次，选笔记/时间轴/速查表任务和你使用的 Agent，复制生成的交接指令，粘贴到该 Agent 的对话中执行。指令包含实际材料位置、目标输出位置及检查要求。

支持通用 Agent，也为 Codex、Claude Code、Cursor、Gemini CLI、OpenCode 提供交接说明。管理器不会自动打开或控制这些 Agent，不包含写作模型套餐，也不能仅凭 CLI 成功就保证笔记质量。

Agent 完成后回到管理器检查产物。文件检查证明指定文件存在，仍需人工核对内容、时间轴和排版。

### 5. 资料库与阅读

“知识库”就是你选择的本机课程资料文件夹：原始材料保存在 `raw`，课程整理结果保存在 `courses`，`site` 是生成的原有阅读网页。它不会因为叫知识库就自动上传到云端。

在“资料库与阅读”同步课程内容，生成/更新阅读网页，再打开本地预览。以后可从统一入口直接打开原网页。GitHub Pages 发布使用“发布准备/生成发布指令”，检查后交给 Agent，并在明确授权后发布选定的网页内容。

## 已实现的功能

| 页面/功能 | 能完成什么 |
| --- | --- |
| 开始使用、账号与保存设置 | 凭据、资料目录、显示名、视觉接口、环境检查 |
| 选课与采集素材 | 最近/可访问课程查询、教师与课次确认、字幕、组合素材、回放定位、补充材料 |
| 任务进度 | 后台排队、阶段/真实数量进度、日志、取消、整门课批量转写与恢复 |
| Agent 写作工作台 | 针对具体课程材料的笔记、时间轴、课次/整门课 A4 HTML 或 LaTeX 速查表交接及文件校验 |
| 资料库与阅读 | 本机内容同步、原网页构建和预览、发布准备与发布交接 |
| 可靠性 | 成品完整性校验、私有音频缓存、同课次并发互斥、分片断流续传、可运行 FFmpeg 检测 |

原项目的 9 个工作流均保留：`/setup`、`/list`、`/trans`、`/note`、`/add`、`/wiki`、`/page`、`/cheatsheet`、`/ralphtrans`。界面提供入口或 Agent 交接；更细的 CLI 参数仍使用原命令。

## 文件与隐私

发行包首次启动使用通用名称，不携带课程内容、个人账号、模型密钥和固定机器地址。使用后：`app/data` 保存启动器和资料目录配置，`app/project/.env` 保存账号配置，`app/project/state` 保存认证及缓存，模型配置在 `app/project/vision-support/config.json`，课程资料在你选择的目录。

这些配置是本机文件，不是加密保险库。分享时分享原始下载 ZIP，不要重新压缩已经使用过的目录，也不要把这些私人文件提交到 GitHub。

关闭浏览器不会停止后台服务，再次启动会复用服务；电脑重启后重新双击入口即可启动。移动已经使用过的资料目录前，先在设置中确认路径和迁移选项，避免引用旧位置。

## 验证与边界

Windows x64 便携包已通过 ZIP 校验、脱敏扫描、空配置首次启动、中文/空格目录重新解压、并发启动、原网页构建、内置浏览器和材料转换测试。当前电脑上管理器首次启动约 2 秒，不能据此保证每台电脑或每种网络都同样快。

已有 69 项后端/CLI/浏览器测试和一个真实课次的 TXT/SRT 验证。尚未在全新实体电脑验证完整流程，其他平台、跨课次批量 ASR、真实视觉接口及 GitHub Pages 发布也未全部做端到端验证。
